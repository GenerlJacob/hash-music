Is the toy XOR hash’s output evenly spread?

We hashed 10,000 random inputs (lowercase strings of 8–24 letters, seed 2710) with our own toy XOR hash. If the output is uniform, every pitch and every byte value turns up about equally often, so the columns in each chart should be level, wobbling only inside the shaded band.

At least one statistic is more than 3 standard deviations from what a uniform source gives: some values come up more often than chance allows.
