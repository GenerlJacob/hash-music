Is SHA-256’s output evenly spread?

We hashed 10,000 random inputs (lowercase strings of 8–24 letters, seed 2710) with our own SHA-256. If the output is uniform, every pitch and every byte value turns up about equally often, so the columns in each chart should be level, wobbling only inside the shaded band.
