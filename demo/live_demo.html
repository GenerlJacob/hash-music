Avalanche at every position of A

Flip one bit of each input byte in turn and count the digest bits that change. An ideal hash changes about 128 wherever the change is; the toy hash changes 1.

The message is padded to whole 64-byte blocks: a 1 bit (0x80), zeros, then the message length in bits as a 64-bit number.

Proof of work: find a number (the nonce) that makes SHA-256(text#nonce) start with zeros. Each extra zero is 16 times more work on average, yet checking an answer takes one hash. Blockchains use this puzzle.

Found it

Each leading zero picks the lowest pitch, G3, so the song starts low: you can hear the work.

Live from the Bitcoin network

A Bitcoin block’s ID is SHA-256 applied twice to its 80-byte header. Miners keep changing one number in that header, the nonce, until the hash starts with about 20 zero hex digits. It is the same puzzle as the Mining tab, where 4 to 6 zeros take seconds. This tab downloads the newest blocks, checks each one with our own SHA-256, and plays it as a song.

This tab downloads public block data from blockstream.info (or mempool.space) only while you have it open. Nothing you type is sent.

Every block song opens with about ten low G3 notes: the leading zeros, made audible.
